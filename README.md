## 📖 About The Project

Welcome to my **Calculator Projects Collection!**

This repository contains two different implementations of a web-based calculator, demonstrating the use of client-side and server-side programming techniques.

The collection includes:

1. **HTML & JavaScript Calculator** – A browser-based calculator that performs mathematical operations instantly without requiring a backend server.
2. **PHP Calculator** – A server-side calculator that processes mathematical expressions using PHP.

These projects demonstrate practical web development concepts, including user interface design, JavaScript DOM manipulation, form handling, server-side processing, and input validation.

## 📌 Projects Overview

<details>
<summary><b>1. 🌐 HTML & JavaScript Calculator (Client-Side)</b></summary>

### 🚀 Live Demo

**[Open HTML Calculator](https://lulieeliyas.github.io/simple-calculator-in-Html/)**

### 📖 Description

A fully functional and responsive web-based calculator developed using HTML5, CSS3, and Vanilla JavaScript.

All mathematical calculations are performed directly in the user's browser, making the application fast, lightweight, and easy to use.

### ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🎨 Modern and attractive user interface.
- ⚡ Instant mathematical calculations.
- 🖱️ Interactive buttons with hover and click effects.
- 📱 Responsive design for desktop and mobile devices.
- ⚠️ Error handling for invalid mathematical expressions.
- 🚀 No backend or database required.

### 🛠️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Lulieeliyas/simple-calculator-in-Html.git
   ```

2. Open the project folder.
3. Locate `index.html`.
4. Open it in your preferred web browser.

**No additional installation is required!**

### 🌍 Deployment

The HTML/JavaScript calculator is hosted using GitHub Pages.

**Live URL:** https://lulieeliyas.github.io/simple-calculator-in-Html/

</details>

<details>
<summary><b>2. 🖥️ PHP Calculator (Server-Side)</b></summary>

### 📖 Description

A server-side calculator developed using HTML5, CSS3, JavaScript, and PHP.

Unlike the HTML/JavaScript version, this implementation sends mathematical expressions to a PHP script for server-side processing and returns the calculated result.

### ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🖥️ PHP-based server-side calculations.
- 🔐 Input validation and expression filtering.
- 🎨 User-friendly calculator interface.
- ⚡ JavaScript-powered button interactions.
- 📋 Form submission to the PHP backend.
- ⚠️ Error handling for invalid expressions.

### ⚠️ Important Hosting Information

**GitHub Pages does not support PHP execution.**

GitHub Pages only hosts static websites. Therefore, the PHP calculator requires a hosting environment with PHP support.

You can use:

- XAMPP (Local Development)
- WAMP / MAMP (Local Development)
- Hostinger (PHP Hosting)
- InfinityFree (PHP Hosting)
- cPanel-based hosting

### 🛠️ How to Run Locally

**Step 1: Install XAMPP**

Download and install XAMPP from:

https://www.apachefriends.org/

**Step 2: Start Apache**

Open the XAMPP Control Panel and start the Apache service.

**Step 3: Place Your PHP File**

Copy `index.php` into your XAMPP `htdocs` directory:

```text
C:\xampp\htdocs\calculator\
```

**Step 4: Open Your Browser**

Visit:

```text
http://localhost/calculator/
```

Your PHP calculator should now be accessible through your local server.

### 🌍 Live Hosting

To publish the PHP calculator online:

1. Choose a hosting provider that supports PHP.
2. Upload your `index.php` file.
3. Configure your hosting environment.
4. Open your assigned domain to access the application.

</details>
